# XR课件案例：第一版内容与版式提案

日期：2026-10-19

状态：用户已授权直接实施；首版已添加中英文详情页并接通首页卡片。

## 定位与范围

推荐以“老师如何把专业3D模型组织成可讲解的课件”为主线，沿用现有模型编辑器案例的排版骨架。XR资源平台、模型编辑器和Sync Space用于说明课件的上下游关系，各自的完整功能不在本案例展开。3D说明书不纳入本页。

对比过的方向：直接迁移旧页能保留材料，但叙事较散；把整个XR体系合成一页能交代范围，但主线过宽；推荐重组旧页材料，聚焦XR课件创作。

## 版式与视觉

复用模型编辑器的大标题、大幅产品截图、角色信息区、左标题右说明、宽幅证据图和章节导航。桌面按其现有章节导航布局，窄屏沿用该页的阅读节奏与单列布局。

延续白底、克制的灰阶文字与留白，紫色只用于本项目的强调和媒体背景，呼应首页XR课件卡片。主体使用真实课件编辑器界面；首页现有模型播放视频用于展示教学素材，不把它误标为课件编辑器界面。

章节导航：概览 / 问题 / 方向 / 方案 / 使用 / 回顾。

## 01 首屏

主标题：把专业3D模型，组织成课堂可讲的课件

副标题：面向职业教育教师的XR课件创作工具，在熟悉的演示文稿流程中插入专业模型，组织教学内容，并在头盔端打开使用。

主视觉：旧作品集中的真实课件编辑器截图，以足够尺寸展示课件编排和模型内容；保留截图比例，不重绘虚构界面。

## 02 概览：从展示模型，到组织一堂课

正文：职业教育中的结构与原理讲解，需要把模型、文字和媒体放进同一条教学思路。XR课件让教师以制作演示文稿的方式组织内容，再将专业模型带入讲解。

角色：体验设计；旧页记载的工作包括需求整理、任务优先级和视觉语言设计。只据旧页和用户确认呈现，不沿用模型编辑器的时间或协作对象作为本项目事实。

配一条简短关系图：资源库 → XR课件〔按需进入模型编辑器〕→ Sync Space（头盔端）。

## 03 问题：有模型，还需要适合备课的创作方式

沿用旧页记载的7位职校教师访谈，概括为三类诉求：需要更多辅助讲解的仿真工具；需要丰富的专业内容；现有界面与视觉体验需要改善。不编造逐字引语、访谈时间和验证结果。

版式：短背景说明 + 三个诉求卡片；每项连接到设计关注点：教学表达 / 素材可获取性 / 界面清晰度。

## 04 方向：保留课件编排习惯，补足3D表达能力

旧页比较过PowerPoint、Google Slides和EON-XR。这里作为当时的方案参考，概括为“演示文稿编排”与“围绕模型讲解”两种方式，不把旧竞品判断当作当前产品能力事实。

三个设计目标：降低课件创作的理解成本；让专业素材更容易查找和复用；在课件里支持结构与原理讲解。

版式：精简对比图 + 三条设计目标。不复制模型编辑器的布局探索历史，也不补造本项目不存在的A/B方案。

## 05 关键方案一：让模型选择跟着备课发生

主文案：老师可以在编辑课件时选用模型，也可以先在资源库收藏，等备课时再使用。两条路径分别照顾即时找素材和提前积累素材的需要。

证据：旧页的内容库界面与相关动图。流程并排呈现：编辑课件 → 选择模型 → 插入；浏览资源库 → 收藏 → 后续备课时选用。

旧页提到内容库体验优化。前后对照只有在源素材确实支持时展示，不依据文件名推断改版结果。

## 06 关键方案二：围绕教学内容组织编辑空间

主文案：课件编辑要让教师持续判断内容如何排列、模型放在哪里，以及当前修改的对象。用真实编辑器界面解释编排区域、模型内容和编辑工具各自承担的任务。

证据：旧页“弹窗改为自适应设计”相关截图。先核实图像显示的具体变化，再撰写图注与决策说明；不把自适应一词直接推断为手机端适配。

版式：左侧解释任务，右侧产品截图；若旧素材支持，再加入可切换的前后状态。首版无需为了交互而新增滑块或轮播。

## 07 关键方案三：让模型服务于讲解

主文案：专业模型进入课件后，还需要按讲解需要调整展示方式。旧页提到视角、爆炸图、原理动画和操作录制；用现有材料展示它们如何帮助说明结构和运动过程。

证据：旧页模型编辑相关图像与动图；现有ppt视频可作为补充演示，需先检查视频实际内容。

模型编辑器的详细工具布局、材质与状态规范通过关联链接指向现有案例，不在本页重复展开。

旧页提到“双击切换显隐”，只有核实相关画面后才作为一个细节展示，不宣称已验证效率提升。

## 08 使用：在Sync Space中打开课件

主文案：制作好的XR课件可以在Sync Space头盔端打开查看，让内容从备课进入头盔端使用。

配一幅经过核实的头盔端截图，明确图注是模型查看或资源入口。现有Figma截图不能直接证明完整课件播放流程，因此不将其标作课件播放实录。不补造发布按钮、同步机制或多人授课功能。

资源平台与Sync Space详情尚未有本地案例路由时，使用文字说明，不生成失效按钮。
