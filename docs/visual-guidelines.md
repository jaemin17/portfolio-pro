# 网站视觉规范

[本地规范页](http://localhost:3000/zh/style-guide/) · [English](http://localhost:3000/en/style-guide/)

这份规范记录网站已经形成并广泛复用的视觉基础。页面采用 Geist 式分类与表格结构，效果、数值和用途并列展示。

## 字体

| 内容 | 字体 | 范围 |
| --- | --- | --- |
| 中文 | Noto Sans SC | 常规标题、段落与说明 |
| 英文与数字 | Geist | 常规内容文字 |
| 英文等宽文字 | IBM Plex Mono | 顶部导航、部分项目元信息 |

沿用全局字体回退机制；主要字体不可用时使用系统字体。首页问候与手写装饰有独立字体，不将装饰用途扩展到正文。

## 字重

| 用途 | 字重 | 变量 |
| --- | --- | --- |
| 正文 | 400 / Regular | --fw-body |
| 常规标题 | 500 / Medium | --fw-heading |
| 正文重点词句 | 500 / Medium | --fw-emphasis |

标题、重点与正文分别定义用途。HTML 的 strong/b 全局默认继承字重，强调外观由明确的样式类控制。装饰展示、少量项目内部标注保留局部字重。

## 基础字号

以默认根字号 16px 换算；实现使用 rem 变量。

| 用途 | 字号 | 变量 |
| --- | --- | --- |
| 共用案例 hero 宽屏标题 | 42px | --fs-display |
| 内容标题 | 26px | --fs-title |
| 副标题、突出说明 | 20px | --fs-subtitle |
| 常规正文 | 16px | --fs-body |
| 标签、导航、简短说明 | 14px | --fs-label |
| 辅助说明、日期、图注 | 12px | --fs-caption |

字号按内容角色使用，不与 h1–h6 一一绑定。同一基础字号可以用于不同级别的语义标题。

共用 featuredHero 的标题在 ≤760px 时切换为 26px；不将这条规则套在所有项目自定义 hero 上。首页展示字、项目自定义标题以及已有中间字号保持各自定义。

正文用于连续阅读；说明补充标题、操作或媒体；图注依附对应媒体；日期与元信息描述时间、平台等属性。先判断内容用途，再选用已有文字样式。字号与灰度分别决定，不能因为文字较小就一律设为弱文字，也不将所有长段落自动改成同一灰度。普通辅助图注和日期以12px为默认，不仅因为项目不同就改变普通图注字号。媒体内标题、重点标注或承担正文说明的内容按独立文字角色定义。

## 阅读行高

| 内容情境 | 常用行高 |
| --- | --- |
| 全局排版默认 | 1.5 |
| 案例正文区域的简介、短说明、普通阅读列表 | 1.65 |
| 案例正文区域的连续叙述、背景、反思长文 | 1.85 |

七个现行案例的正文阅读区域按上述用途选用两档行高，中英文及宽窄屏使用同一角色规则，不因项目不同另选中间值。内容角色按功能确定，不按当前屏宽的行数判断。

项目首屏展示、标题、普通图注、观点/提示区、媒体内部文字不套用正文行高，保留各自定义；关于页保持现状（中文正文1.9）。段落外边距与列表条目间距另行定义，不由行高推导。

## 基础色彩

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 主文字 --text-primary | rgb(0 0 0 / 90%) | 标题与需要突出的文字 |
| 次文字 --text-secondary | rgb(0 0 0 / 60%) | 案例普通阅读正文、一般说明、次级信息、普通辅助图注 |
| 弱文字 --text-muted | rgb(0 0 0 / 40%) | 日期、弱元信息、非关键短标注 |
| 页面背景 | #fff | 默认页面底色 |
| 基础边框 --border | #eee | 边框、内容分隔线 |

三档灰色按内容角色使用。项目主题表达、媒体或设备内部文字、观点提示等独立用途可以保留专用颜色，不以“原来有局部色值”为普通案例正文的例外理由。边框变量允许项目作用域覆盖。

案例中的普通阅读正文、设计叙述和普通阅读列表统一使用次文字色60%，不额外叠加整段透明度；中英文和不同屏宽保持相同灰度。标题、重点词、主题标签、观点提示及媒体内部文字保留各自层级，不套用普通正文规则。关于页的既有40%灰度不在此次案例规则范围内。字号、字重、行高与间距仍按各自角色定义。

白底或浅色面板下、用于解释图片的普通辅助图注统一使用次文字色60%，不因项目不同改用另一种灰或蓝灰。图注中的标题、主题强调和深色媒体中的白字按各自角色保留；40%弱文字不作为普通辅助图注的默认色。

反思长文正文组件的普通段落统一使用次文字色60%，重点词使用主文字色90%，段落不再叠加元素透明度；中英文及不同屏宽保持同一灰度。观点提示与结语保留自己的主文字层级。此规则限定于该正文组件，不自动覆盖其他页面已有段落或关于页的灰度。

项目主题色与背景各自定义。蓝色和橙色存在多个用途与取值，不指定一个全站唯一强调色。

## 布局

内容居中排列、受最大宽度和视口约束；具体宽度按组件选择。

| 范围 | 规则 |
| --- | --- |
| 主站基础横向留白 | --page-gutter = 30px；首页部分断点覆盖为 32px，项目留白另定 |
| 共享案例外层 | 最大 1080px，左右内边距 30px，宽屏使用侧导航＋正文 |
| 共享案例正文 section | 最大 840px；媒体区域可使用其他宽度 |
| 共享案例侧导航 | ≤768px 隐藏，布局改为单列，外层横向内边距清零；项目正文仍控制自身留白 |

共享案例正文的 840px 包含该 section 自身的内边距，不等于所有视口下的文字实际行宽。宽度都是上限，窄屏随可用空间收缩。

不建立单一的全站正文宽度。首页、关于页与独立媒体面板的专用容器继续保留，不扩展为所有页面规则。

首页作品卡片封面容器统一为3:2，使同排卡片的文字起点一致。满幅封面沿用原有铺满方式，带界面内边距的封面和较高素材以contain缩放适配，保留完整内容。图片与视频播放前后的封面容器尺寸一致；该规则仅用于首页卡片，不改变案例页媒体比例。实现位于ToolProjectList.tsx和首页page.module.css。

### 阅读间距

共用案例内容区已有 **40px下外边距**，仅适用于使用该共用内容区的章节；引导区、策略区、长文分节和页面结尾有自己的间距。案例目录的 **16px条目间距** 也仅用于该目录，不能直接套在正文列表上。

案例同一区块内，相邻普通连续正文段落之间的距离为 **20px**，中英文与宽窄屏相同。适用于Selfly定位、体验和反思的连续正文，以及VR教育UI视觉说明中的连续段落。只规范相邻正文之间的空隙；首尾留白、标题到正文、列表条目、观点提示和媒体说明保持各自定义，不为当前没有对应连续段落的区域修改未使用样式。

章节之间、标题到说明、连续段落、列表条目和容器内边距分开处理：同一用途沿用对应角色规则，修改共用规则前检查所有引用。不预设全站4px/8px网格；具体页面值与用途例外保存在内部对齐记录。规范展示页的纸张内边距、表格间距和色块尺寸只用于展示，不作为网站其他容器的标准。

案例中普通设计说明列表的相邻条目间距为 **8px**，中英文与宽窄屏相同。适用于Selfly设计说明、模型编辑器设计决策、VR教育设计重点及XR课件设计决策列表。仅调整条目之间的额外空隙；字号、行高、列表缩进、圆点与重点文字沿用各自角色。反思长条目、观点/提示区列表、导航和媒体内部列表保持独立定义，不套用此值。

这类列表使用共享组件`src/components/CaseDesignList.tsx`及其CSS Module；规范页独立“组件”章节下的“设计说明列表”直接渲染同一组件，目录设有单独入口（#components）。后续共享组件也在此章节展示。组件管理列表结构、默认16px/400/60%、1.65行高与8px条目间距；调用方保留列表上方标题、重点文字与特殊圆点。现有Selfly手机14px字号、XR课件19px缩进及VR教育自定义圆点/0px列表缩进通过局部样式保留，不新增项目名变体。该组件不负责整页布局或段落排版。

## 形状

标签、分类与胶囊形控件常用 **全圆角（胶囊形）**。高度、内边距、颜色和交互状态由具体组件定义，不能因为形状相同就视为同一种按钮。

卡片、提示区域、图片和设备外框已有多种圆角，本规范不把它们统一成一个数值。

### 标签、按钮与链接

| 类型 / 范围 | 已有用法 | 状态与限制 |
| --- | --- | --- |
| 静态文本标签 | 只标记类别、属性等内容；全圆角（胶囊形） | 不承担切换或跳转，不因为形状像按钮就增加交互；字号和内边距沿用所用标签组件 |
| 首页分类筛选 | 14px、400、全圆角；最小高度40px，内边距8.8px 18px | 默认次文字色、12%黑边框；悬停主文字色、22%黑边框；选中为主文字色底、白字；键盘焦点1px主文字色描边、偏移4px |
| 首页“更多项目” | 14px、400、全圆角；最小高度40px，内边距8.8px 18px | 默认次文字色、基础边框；悬停主文字色、18%黑边框；键盘焦点1px主文字色描边、偏移4px |
| 普通链接 | 用于打开页面、章节或外部目标；基础样式继承文字色、不加下划线 | 具体组件可增加下划线、主题色及焦点描边；不将筛选按钮的选中底色套用到普通链接 |

上表记录现有组件行为，不建立所有按钮通用的尺寸或状态。卡片链接也有自己的边界：作品索引与个人工具卡片现有外圆角均为20px，但两者内边距、悬停和焦点规则不同；不因此合并成同一个组件。媒体比例、内部预览圆角、设备外框和项目提示区继续按用途保留。

网站交互色用于表示可操作或当前状态，项目主题色用于项目自身的表达。两者可能使用相近颜色，但不能只因色号接近就合并。普通链接的主题色也不自动成为全站按钮颜色。

## 导航

规范展示页将导航归入“组件”，不再单设导航章节：章节目录的全部规则放在其示例旁，站点顶部菜单与语言切换合并为“站点导航”示例。此处保留正式文字定义供实现查阅。

| 组件 | 文字 | 状态与布局 |
| --- | --- | --- |
| 全站顶部英文导航 | IBM Plex Mono，14px，400，行高 1 | 默认次文字色，悬停与当前页面使用主文字色；顶部居中排列 |
| 顶部语言切换 | 12px，400 | 默认弱文字色，悬停改为次文字色 |
| 共享案例章节导航 | 16px，400，行高 1.5 | 项目间距 16px，宽屏 sticky top 40px；默认 #8b8b8b，当前章节与悬停 #333 |

规范目录与案例目录共用`src/components/SectionNav.tsx`及其CSS Module，均为16px、400、行高1.5。组件管理锚点跳转、阅读位置跟随、当前章节/悬停#333和键盘焦点2px #93c5fd描边、偏移4px；这些焦点规则仅用于此组件。

页面负责目录位置和可见性：案例目录沿用16px条目间距、#8b8b8b默认色、sticky top40px和≤768px隐藏；规范目录保留宽屏左侧、20px纵向条目间距、60%默认色，≤768px移到顶部横向换行（行距12px、列距24px）。不因复用组件改变这些布局用途。组件章节的“章节目录”示例使用同一组件的preview模式，在普通文档流中显示，保留悬停、点击切换示例自身选中状态及键盘焦点；不跳转页面，也不跟随实际页面滚动。示例用按钮表达局部选择，实际使用的目录仍为完整锚点链接。

“站点导航”示例直接使用`src/components/SiteHeader.tsx`的preview模式，使用相同菜单、字体和状态样式；预览在文档流中展示，按钮只切换本地选中状态，不跳转、不打开简历、不切换整页语言，也不重复创建site-menu标识。实际站点头部沿用链接和既有页面/语言目标。
