# 视觉规范候选工作文档

正式规则见 [视觉规范](visual-guidelines.md)。本文件只保留尚未形成一致用法、需要继续判断的项目；已广泛复用的基础规则已于 2026-11-15 收入正式规范，不再逐条询问。

| 待讨论内容 | 现状 | 下一步 |
| --- | --- | --- |
| 项目主题色 | 多种蓝色、Selfly 橙色和按钮橙色并存 | 按主题与交互用途判断，不批量替换 |
| 行内强调装饰 | Selfly细下划线、其他项目不同粗细或色彩处理 | 判断哪些是项目表达，哪些值得共享 |
| 放大观点、提示区域 | Selfly已形成局部用法，其他案例有不同处理 | 保留局部偏好，决定是否形成共享内容组件 |
| 间距体系 | 章节与同组条目的用途不同，没有统一网格 | 按内容关系比较，不从高频数值倒推标准 |
| 卡片和媒体圆角 | 6、8、10、12、14、16、18、20、22等并存 | 按组件用途归类，再决定是否收敛 |
| 页面容器和断点 | 首页、关于页、案例和媒体宽度各异；760/768等不同断点 | 对边界视口测试，不统一成一个宽度或断点 |
| 局部字体字重与灰度 | 存在300/600字重、40%长段落、不同opacity | 单独比较实际效果，不自动修改 |

Selfly 已接受的阅读偏好保存在 [内部盘点](visual-audit.md)；候选讨论不会覆盖这些既有决定。新规则只有在获得明确决定或足够的重复使用证据后，才进入正式规范与展示页。

## 2026-11-16 检查决定

- 关于页现有40%灰度按用户决定保留，不实施40%→60%的建议。现行规范允许局部色值和透明度覆盖，不将该差异判为必须迁移。
- 模型编辑器600步骤编号、XR课件300展示编号先保留；它们不是常规正文和标题，不直接套用400/500规则替换。
- 素材库与个人工具的独立hero尺寸，以及各项目主题色、媒体圆角保留；尚未形成新通用规则。
- 全站基础检查结果、各页剩余项和证据见[全站对齐记录](visual-alignment.md)。没有新增正式视觉规则或修改网站样式。
- 间距已按章节、段落、列表、图注和控件记录九页宽窄屏现状；尚没有足够依据制定统一数值，保留各用途用法。
- 首页分类结果标题曾有400/500字重讨论；用户最终选择删除这处重复标题，已经实施，不再作为待收敛字重项。

- 收尾已将现有文字角色、共用案例40px下距、分类/更多/普通链接职责和状态同步到正式规范及中英文规范页，未改变作品页面样式。
- **已确认并实施的展示取舍**：用户同意规范页≤640px的字体、字重、控件等表格改为每条上下排列。原有基础字号表保持已有布局，641px及以上保持三列。只影响规范页，不外推为全站卡片规则。见[实施截图](visual-audit/2026-11-16/guidelines-controls-mobile-stacked.jpg)。

## 逐项收敛讨论：第一项，正文跨屏灰度

用户要求一次确认一个差异，逐步收敛规范。当前只讨论，不修改页面或正式规则。

- 现状：Selfly反思同一普通段落，1280px为90%文字色叠加opacity .88，白底上约等效79.2%黑；390px为60%文字色、opacity 1。两端均为16px、400、行高1.85。
- 建议：同一内容角色不因屏幕宽度改变灰度。先在Selfly反思普通段落试点中英文统一60%，不叠加整段透明度；重点词使用90%层级，保留标题、橙色分节、观点提示的独立用途。字号、字重、行高和间距不随此次调整。
- 范围：仅Selfly反思普通段落试点；不修改所有引用Selfly CSS的页面，不改用户决定保留的关于页40%。试点确认后再讨论推广范围。
- 状态：用户已同意并实施；Selfly反思普通段落中英文各屏均为60%且opacity为1，重点、观点提示与结语保持90%。正式规范与规范页同步。调整前现状见[电脑](visual-audit/2026-11-16/selfly-body-gray-current-1280.jpg)、[手机](visual-audit/2026-11-16/selfly-body-gray-current-390.jpg)及[计算样式](visual-audit/2026-11-16/selfly-body-gray-comparison.json)。
