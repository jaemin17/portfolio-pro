# Established website styles

**Goal:** 按用户授权，把网站已经广泛使用的样式直接收入正式规范与 Geist 式展示页。

**Scope:** 记录现状，不改已有页面样式。延续正式规则、候选讨论与内部证据分离，不在规范页放来源页面链接或确认状态。

## 收录标准

1. 全局默认且由实际内容继承；或全局变量在多个现行页面样式中引用。
2. 多个不同页面共用同一个组件及其规则。
3. 相同数值在多个页面以相同用途出现。单文件大量重复不单独构成证据。
4. 只声明而未用于现行页面、重定向路由、规范页自身，不计作独立支持证据。

- [x] 规范页复用现有全局变量，延续表格展示；提供章节锚点、文字/颜色/形状实例。不新增项目主题标准、不统一历史页面样式。

## 排除

不统一蓝色与橙色色号、段落间距、所有圆角、所有容器宽度或断点；不把 Selfly 下划线和观点框直接当作全站样式。装饰字体为局部用途，不扩大使用范围。需要设计判断的差异仍在候选文档。
