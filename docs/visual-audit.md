## 1. 已存在的全站基础

来源：`src/app/globals.css`、`src/app/layout.tsx`。

| 类别 | 当前定义 | 说明 |

## 3. 布局与组件

- 共享案例布局：`src/components/CaseStudy.module.css` 使用导航列加正文列，最大宽 1080px，横向内边距 30px；≤768px 隐藏侧导航并改为单列。
- Selfly 案例区最大宽 840px，≥769px 增加左右各 30px 内边距。1280px 样本反思正文实际宽 780px；390px 样本正文宽 350px。
- 首页采用更宽的作品展示区域，关于页保持 416px 的文字列；两者服务不同内容，暂不合并。
- 首页卡片圆角 20px；标签与按钮使用胶囊圆角。Selfly 反思观点框 10px、判断区域 12px。其他案例媒体面板还有多种圆角，不能仅按出现次数制定统一值。
- 共享案例导航已有 2px 焦点描边、4px 偏移。后续展示页应包含真实交互状态，而非只有静态外观。

### 没有提升为通用规则的内容

- 只在首页使用的 page-max 容器，以及仅关于页使用的 content-max 宽度，不因变量写在 root 就认定全站广泛使用。
- 首屏装饰字体、项目主题蓝/橙色、不同卡片圆角、所有段落间距、统一4px/8px间距网格均没有足够的一致性依据。
- 下划线 .75px 是 Selfly 的明确局部规则；其他项目还有1px等不同处理，不写成全站唯一样式。
- 不把规范页新增展示参数计入复用统计，不改实际作品页来迎合统计。
